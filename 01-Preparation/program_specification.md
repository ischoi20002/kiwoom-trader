이 문서는 [Get_Price_GUI.py](file:///c:/Users/ischo/OneDrive/%EB%B0%94%EC%9D%B4%EB%B8%8C/Get_Price_GUI.py)를 중심으로 한 시스템 구축 방식과 매매 로직의 상세 구현 내용을 설명합니다.

## 1. 시스템 아키텍처 개요

본 프로그램은 **키움증권 REST API 및 웹소켓**을 기반으로 하며, 스윙 매매를 위한 종목 발굴부터 실시간 타점 포착까지 전 과정을 자동화한 GUI 애플리케이션입니다.

- **Frontend**: Python `tkinter` (GUI), `ttk` (테마 적용 트리뷰)
- **Data Engine**: `pandas` (수치 연산 및 기술적 지표), `FinanceDataReader` (과거 일봉/종목 리스트 수집)
- **Networking**: `requests` (REST API 통신), `websockets` (실시간 서버 통신), `asyncio` (비동기 처리)
- **Concurrency**: `threading` (GUI 동결 방지), `ThreadPoolExecutor` (병렬 데이터 수집)

## 2. 주요 모듈 및 로직 흐름

### 2.1 기초 데이터 관리 (Foundation Data)
- **토큰 관리**: `TokenManager`를 통해 키움 REST API 인증 토큰을 발급 및 갱신합니다.
- **KOSPI 상위 500 리스트**: 시가총액 기준 상위 500개 종목을 수집하며, 우선주를 제외한 후 로컬 캐시([kospi_top_500.csv](file:///c:/Users/ischo/OneDrive/%EB%B0%94%EC%9D%B4%EB%B8%8C/kospi_top_500.csv))에 저장합니다.
- **네이버 테마 매핑**: 네이버 금융 상위 테마를 크롤링하여 종목별 테마 정보를 매핑합니다. ([naver_themes.json](file:///c:/Users/ischo/OneDrive/%EB%B0%94%EC%9D%B4%EB%B8%8C/naver_themes.json))

### 2.2 전략 종목 선정 (Screening Phase)
종목 선정은 5단계 필터링 및 가점 시스템(`v2.1 Ranking`)을 거칩니다:
1. **거래대금 필터**: 최근 5일 평균 거래대금이 사용자 설정값(기본 40억) 이상인 종목.
2. **이평선 수렴**: 5일선(MA5)과 20일선(MA20)의 이격도가 사용자 설정값(기본 3%) 이내인 종목.
3. **RSI 범위**: 일봉 기준 RSI(14)가 40 ~ 52 범위 내에 있어 반등 초입인 종목.
4. **거래량 분출**: 최근 10일 이내에 전일 대비 150% 이상의 거래량 폭발 이력이 있는 종목.
5. **종합 가점(Score)**: RSI 탄력성(30%), 이평 밀집도(40%), 거래대금 규모(20%), 20일선 근접도(10%)를 합산하여 최종 점수 산출.

### 2.3 실시간 감시 및 타점 포착 (Monitoring Phase)
웹소켓을 통해 초단위 시세를 수신하며, 실시간으로 기술적 지표를 갱신합니다.

#### **A. 틱-투-바(Tick-to-Bar) 변환 로직**
- 수신되는 모든 틱(Tick)의 가격을 **현재 생성 중인 15분봉의 종가(Close)**로 즉시 업데이트합니다.
- 고가(High), 저가(Low), 거래량(Volume)을 실시간으로 누적하여 지표의 정확도를 확보합니다.

#### **B. 핵심 지표 계산**
- **실시간 RSI**: 15분봉 데이터 14주기를 기준으로 Wilder's Smoothing 방식을 적용해 틱 단위로 재계산합니다.
- **15분봉 MA**: MA5와 MA20의 골든크로스 여부를 실시간으로 추적합니다.
- **체결강도**: 실시간 매수/매도 하체결량 비율을 확인합니다. (FID 228 기반)

## 3. 매수 타점(Buy Signal) 확정 조건

최종 매수 신호(전체 행 노란색 하이라이트)는 아래 **5가지 조건이 동시에 만족**될 때 발생합니다.

| 조건 구분 | 세부 내용 | 제한 및 해제 조건 |
| :--- | :--- | :--- |
| **시간 가드** | 09:00 - 15:30 (정규장 시간) | 장외/프리마켓 신호 생성 불가 |
| **골든크로스** | 15분봉 MA5 가 MA20 상향 돌파 | 발생 후 30분 초과 시 폐기 |
| **RSI 강세** | RSI(14) 50 돌파 (RSI Signal) | 돌파 후 45분(봉 3개) 경과 시 폐기 |
| **체결강도** | 실시간 체결강도 120% 이상 | - |
| **거래급증** | 1분 내 비정상 거래량 급증 포착 | - |

> [!IMPORTANT]
> **신호 자동 취소**: 현재가가 15분봉 MA5를 하향 이탈하거나, RSI가 50 미만으로 떨어지면 즉시 신호가 해제됩니다.
